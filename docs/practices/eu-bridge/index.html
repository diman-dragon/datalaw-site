EU Bridge: для европейских юристов

Программа для европейских юридических фирм: надёжный со-советник по российскому праву, экспертный свидетель и исполнитель на российской стороне. Все услуги доступны в формате white-label, соглашения о конфиденциальности подписываем по умолчанию.

Обсудить дело

  • Правовые заключения по российскому праву

    Ст. 248.1 АПК

    Экспертные заключения для европейских судов и арбитражных трибуналов: антиисковые меры, контрсанкционное законодательство, юрисдикционные конфликты, гражданское и корпоративное право. Выдаём на русском, английском, немецком и французском.

  • Выход из активов через Правкомиссию

    Правкомиссия

    Сопровождение выхода иностранных акционеров из российских активов: заявления в Правительственную комиссию, структурирование и исполнение сделки, включая переговоры о дисконте по действующим правилам.

  • Сбор доказательств в России

    Апостиль

    Допросы свидетелей, истребование документов, нотариальное удостоверение, апостиль. Соответствие и российскому праву, и процессуальным требованиям иностранного суда.

  • Со-советник по делу

    White-label

    Формальные соглашения о со-советничестве для дел, где нужен постоянный российский эксперт. Выступаем экспертным свидетелем, готовим показания, консультируем в ходе слушаний.

  • Контрсанкционное регулирование

    Указы № 95, 138

    Анализ Указов Президента РФ № 95, № 138 и № 254. Стратегии для европейских кредиторов по получению платежей от российских должников при валютных ограничениях, законные платёжные маршруты, которые признают российские суды.

  • Сопровождение российского процесса

    Параллельный процесс

    Мониторинг параллельных российских производств, влияющих на европейское дело клиента: участие в заседаниях, перевод судебных актов, рекомендации по согласованию двух процессов.
